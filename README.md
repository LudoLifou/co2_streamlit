# streamlit
To launch the streamlit:
- Open a terminal session in the repository root
- Create "co2" environnement: Type `conda env create -f  environment.yml` 
- Activate your conda "co2" environment: `conda activate co2`
  (Note: under VSCode, use a “Command prompt” terminal)
- (You'll also need to install sqlite3 to process database actions)
- run `streamlit run app.py`

## **Instructions**
`pip install Streamlit`  ou environnement avec streamlit

Dans le prompt :
streamlit hello         # ouvre une page de test "Welcome to Streamlit!" dans le navigateur  
streamlit run app.py    # démarre la page web streammlit_perso - a execueter en ligne de commande dans le dossier de "app.py"  
Ctr C                   # quit
